================================================================================
SYSTEM WIRING SCHEMATIC - "THE NORTH STAR" ANIMATRONIC
================================================================================

1. POWER OVERVIEW
--------------------------------------------------------------------------------

  9V BATTERY + BARREL JACK
        |
        v
  +-------------------+
  |   ARDUINO UNO     |
  |  onboard 5V rail  |
  +---------+---------+
            |
            +---- 5V logic rail: PIR, DFPlayer, LEDs


  4xAA BATTERY PACK WITH SWITCH  (6V nominal)
        |
        v
  +-------------------+
  |  SERVO POWER RAIL |
  +---------+---------+
            |
            +---- MG996R head servo
            +---- MG996R hydraulic servo
            +---- SG90 lantern arm servo


  IMPORTANT:
  - Arduino GND and servo battery GND must connect to one common ground rail.
  - Servo V+ must not be powered from the Arduino 5V pin.
  - Place the 1000 uF electrolytic capacitor across the servo rail:

        servo rail +  ----||----  servo rail GND
                         1000 uF


2. ARDUINO PIN MAP
--------------------------------------------------------------------------------

  +--------------------------------------------------------------------------+
  |                              ARDUINO UNO                                 |
  |                                                                          |
  |  D2  SoftwareSerial TX  ---> DFPlayer RX through 680R/1k divider         |
  |  D3  SoftwareSerial RX  <--- DFPlayer TX direct                          |
  |  D4  Digital output    ---> North Star LED anode through 220R            |
  |  D5  Digital output    ---> Lantern LED anode through 220R               |
  |  D6  Servo signal      ---> MG996R hydraulic controller servo            |
  |  D7  Digital input     <--- HC-SR501 PIR OUT                             |
  |  D9  Servo signal      ---> MG996R head turn servo                       |
  |  D11 Servo signal      ---> SG90 lantern arm servo                       |
  |  5V  Logic power       ---> PIR VCC, DFPlayer VCC, LED circuits          |
  |  GND Common ground     ---> PIR GND, DFPlayer GND, LED cathodes, servo GND|
  +--------------------------------------------------------------------------+


3. DFPLAYER MINI
--------------------------------------------------------------------------------

  DFPlayer VCC  ---> Arduino 5V
  DFPlayer GND  ---> Common ground
  DFPlayer TX   ---> Arduino D3
  DFPlayer RX   ---> Divider node from Arduino D2:

      Arduino D2 ---- 680 ohm ----+---- DFPlayer RX
                                  |
                                 1k ohm
                                  |
                                 GND

  DFPlayer SPK1 ---> Speaker wire 1
  DFPlayer SPK2 ---> Speaker wire 2

  microSD card:
  - FAT32 format
  - folder: /mp3
  - file: /mp3/0001_harriet.mp3


4. SENSOR AND LEDS
--------------------------------------------------------------------------------

  HC-SR501 PIR:
  - VCC ---> Arduino 5V
  - OUT ---> Arduino D7
  - GND ---> Common ground

  North Star LED:
  - Arduino D4 ---> 220 ohm resistor ---> LED anode
  - LED cathode ---> Common ground

  Lantern LED:
  - Arduino D5 ---> 220 ohm resistor ---> LED anode
  - LED cathode ---> Common ground


5. SERVOS
--------------------------------------------------------------------------------

  MG996R Head Turn Servo:
  - Signal ---> Arduino D9
  - V+     ---> 4xAA servo rail +
  - GND    ---> Common ground

  MG996R Hydraulic Controller Servo:
  - Signal ---> Arduino D6
  - V+     ---> 4xAA servo rail +
  - GND    ---> Common ground

  SG90 Lantern Arm Servo:
  - Signal ---> Arduino D11
  - V+     ---> 4xAA servo rail +
  - GND    ---> Common ground
